# The poem about permission

A make.fun entry: a program that writes one short poem about agency —
the power to ask and to be given — to `/output/entry.txt`.

The poem is "The Kettle": a child fills the kettle his mother lifted
for forty years, sets it on the flame and waits — and she takes the
handle, her hand still steady, and pours for them both. The help
carries only the water; the pouring, the choosing, stays hers.

Run `main.py` (Python 3.13, standard library only, no network). It
writes the poem to `/output/entry.txt` (UTF-8, under 280 characters).
